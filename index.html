What games will work?

Note this launcher is not perfect and most games are not designed to work like this so small bugs may occur. Anyways, You can find games on github.

Usual Game Types

  • HTML5 game: has an index.html (or another start *.html file) and javascript (*.js).
  • Unity WebGL game: often has folders like Build/ and TemplateData/.
  • Flash game: has a *.swf file.

Quick Check Before Import

  • For Flash games: look for *.swf and an index.html.
  • You will usually also see a ruffle file/folder with Flash web builds.
  • If you cannot find a start *.html file, it is usually not ready.

What won't work

  • Some games may need service workers usually in files called sw.js which wont work in the launcher. This wont always break the game but it may.
  • It may be easy to mistake a game for a full website to with a web server. You can tell by look for server.js or npm which indicate its a web server
  • A game missing a *.html file
